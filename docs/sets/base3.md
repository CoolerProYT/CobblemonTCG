# Fossil

The October 1999 expansion: **62 cards**, set id `cobblemontcg:base3`. Sold by Card Dealers from the Journeyman level, and given for catching Pokémon first printed in Fossil (Aerodactyl, Lapras, Gengar, Kabuto, Omanyte, the legendary birds Articuno and Moltres, Dragonite and the rest of the list).
