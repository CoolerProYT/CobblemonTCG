Every set is a datapack of JSON files, so [new sets](/datapacks/) need no code. Pokémon cards show [Cobblemon's models](/guide/cards#cobblemon-on-the-cards) in the art window, like in game.

## Collecting a full set

A pack never holds the same card twice, but two packs can. How many packs a full set takes depends mostly on the holo rares: with the default holo chance of 1 in 3 and 16 holo rares, a given holo shows up in about 1 pack in 48. Use the [Card Binder](/guide/card-binder)'s sort button to see which numbers you are missing.
