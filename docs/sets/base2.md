# Jungle

The 1999 Jungle expansion: **64 cards**, set id `cobblemontcg:base2`. Sold by Card Dealers from the Apprentice level, and given for catching Pokémon that are in Jungle but not in Base Set, for Pokémon reaching level 50 and 100, and for owning half the Pokédex or more.
